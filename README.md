# semantik-stock

Génération automatique du stock de jours pré-générés de Semantik, dans un dépôt public pour disposer de GitHub Actions gratuitement.
Ce dépôt ne contient que du **code**. Le vocabulaire, les candidats, les filtres, les vecteurs et le plan sont dans un stockage privé et ne passent
jamais par git. Le journal des exécutions est public : il n'affiche que des étapes et des compteurs.

Le code vient du dépôt principal par `scripts/sync-stock-repo.sh` : ne modifiez pas `pipeline/semantik_pipeline/` ici.
